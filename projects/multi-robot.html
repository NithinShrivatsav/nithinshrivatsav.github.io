Decentralized Multi-Robot Control for Capture the Flag

This project implements decentralized coordination strategies for a team of mobile robots playing a Capture-the-Flag game. Robots exhibit emergent behaviors including perimeter defense, decoying, pursuit, and tagging using only local sensing and distributed control protocols. The system was validated in the Robotarium multi-robot testbed.

📘 Algorithmic Breakdown

1️⃣ Cyclic Pursuit Perimeter Defense

Defender robots form a rotating barrier around the flag using cyclic pursuit. Each robot tracks only its neighbor and updates its velocity vector accordingly. This creates a stable circular formation without centralized coordination. 

 Neighbor Pose  →  Relative Vector  →  Rotation Transform
        ↓
 Velocity Command → Robot Actuation

This behavior maintains spacing, connectivity, and adaptability as agents enter or leave the formation.

---

2️⃣ Connectivity-Preserving Consensus for Tagging

When attackers approach, a subset of defenders switches into tagging mode using consensus control. Robots maintain network connectivity while collectively moving toward intruders. 

 Neighbor States → Consensus Filter → Weighted Velocity → Motion

The connectivity constraint prevents communication graph fragmentation while maintaining responsiveness.

---

3️⃣ Reactive Decoy Strategy

A decoy robot intentionally attracts defenders away from the protected zone by maintaining interaction distance while drifting away from the flag. This blended control produces deceptive motion that appears locally aggressive but globally strategic. 

 Distance Regulation + Goal Drift → Weighted Blend → Motion
---

4️⃣ Hybrid Behavior Switching (FSM)

Robots transition between behaviors based on proximity triggers and sensing conditions using a finite-state machine. 

 Sense Event → FSM State → Controller Selection → Motion
